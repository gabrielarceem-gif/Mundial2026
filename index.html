Ajustes y datos

Conexión a Football-Data.org

Tu token ya viene precargado. El plan free da 10 consultas por minuto y cubre el Mundial (competición WC). Cada sincronización gasta 1 consulta.

Importante: Football-Data.org no se puede llamar directo desde el navegador (bloquea por CORS y expondría tu token). Necesitás un mini-proxy gratis. Elegí abajo cómo conectarte.

Con el proxy recomendado, el token vive en el Worker y podés dejar este campo vacío.

Cómo montar el proxy gratis (5 min, una sola vez)

Cloudflare Workers tiene plan gratuito de sobra para esto. Pasos:

  1. Entrá a dash.cloudflare.com → creá cuenta gratis → Workers & Pages → Create Worker.
  2. Borrá el código de ejemplo y pegá el de abajo (ya trae tu token). Poné Deploy.
  3. Copiá la URL que te da (algo como https://mundial.tu-usuario.workers.dev) y pegala arriba en "URL de tu proxy".
  4. Listo: el token queda escondido en Cloudflare y el navegador ya no se queja del CORS.

    
    

  


  

    
Hosting: GitHub Pages

    
Para que la vean entre amigos: creá un repo en GitHub, subí este archivo como index.html, andá a Settings → Pages → Branch main → Save. En un minuto tenés una URL pública. Como el token vive en el Worker (no en este HTML), publicarlo es seguro. Si igual preferís no exponer nada, dejá el repo privado y abran el archivo localmente.
